## Commander staples this stretch

- **Edgar Markov** (D1260) and **The Ur-Dragon** (D1262): eminence, which works from the command
  zone as well as the battlefield.
- **One or more Dragons attack** (D1261), and "that many".
- **Experience counters** (D1263), and **Meren of Clan Nel Toth** (D1264) built on them.
- **Birthing Pod** (D1265), Prime Speaker Vannifar and Repurposing Bay: the search one mana value
  up from what was sacrificed.
- **Flavour words** (D1266): a label like "Magical Tinkering —" in front of an activated ability
  now comes off, as it already did for triggers. Keywords in that place ("Max speed —",
  "Exhaust —") still restrict the ability. This read 32 cards.
- **Show and Tell** (D1267).
- **Eldritch Evolution** (D1268), and searches for "up to X lands, where X is …" with the
  destination in the next sentence.
- **Five more counts** (D1269): your life total, permanent cards in your graveyard, different
  powers, players with more lands, a commander's mana value.

Test changes this stretch:
- **D1266.** A D623 test pinned a made-up "Threshold — {1}: You gain 4 life." as unread. It is now
  read as printed, with no condition. No legal card prints a condition word like that without
  spelling the condition out.
- **D1269.** Ajani, Caller of the Pride now reads whole, so the compiled-against-hand-written
  comparison sees it for the first time. It found one difference: the compiled +1's target has a
  filter function the hand-written one does not. It is listed with that reason, and the
  hand-written card is still the one played.

One gate failed in this stretch: D1266's first run, on a test typecheck (an optional field read
without `?.`). It was fixed and re-gated before any push.
